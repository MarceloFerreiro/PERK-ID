\begin{frame}{Cómo se construye el índice}
  \begin{columns}[T,onlytextwidth]

\begin{frame}{Consulta y ranking}
  \begin{columns}[c,onlytextwidth]

    \column{0.54\textwidth}
      \begin{block}{Funcionamiento}
      A partir de una imagen de consulta, el sistema extrae sus descriptores visuales y busca en el índice las pastillas más parecidas.
      \end{block}

      \vspace{0.2cm}

      \begin{itemize}
        \setlength\itemsep{0.16cm}
        \item Se calcula un vector de características para la imagen de entrada.
        \item Ese vector se compara con los vectores del índice visual.
        \item La búsqueda se realiza mediante vecinos más cercanos.
        \item Como resultado, se obtiene un ranking ordenado por similitud.
      \end{itemize}

    \column{0.42\textwidth}
      \centering

      \begin{tikzpicture}[
        node distance=0.38cm,
        box/.style={
          draw,
          rounded corners=5pt,
          minimum width=4.1cm,
          minimum height=0.58cm,
          align=center,
          font=\scriptsize,
          thick
        },
        arrow/.style={
          -{Latex[length=2mm]},
          thick,
          perkblue
        }
      ]

      \node[box, fill=perkcyan!15, draw=perkcyan] (query) {Imagen de consulta};
      \node[box, fill=perkorange!15, draw=perkorange, below=of query] (desc) {Extracción de descriptores};
      \node[box, fill=perkblue!10, draw=perkblue, below=of desc] (index) {Comparación con el índice};
      \node[box, fill=perkgreen!15, draw=perkgreen, below=of index] (rank) {Ranking Top-K};

      \draw[arrow] (query) -- (desc);

      \begin{block}{Interpretación}
      Cuanto menor es la distancia, mayor es la similitud visual con la imagen de entrada.
      \end{block}

  \end{columns}
\end{frame}

\begin{frame}{Backend FastAPI}
  \begin{columns}[c,onlytextwidth]

    \column{0.54\textwidth}
      \begin{block}{Funcionamiento}
      El backend actúa como intermediario entre la app y el sistema de búsqueda visual: recibe la imagen, consulta el ranking y construye la respuesta final.
      \end{block}

        \item Devuelve una respuesta estructurada con resultados, metadatos y sustancias asociadas.

\begin{frame}{Autoencoder y Bounding Box: módulo experimental}
  \begin{columns}[c,onlytextwidth]

    \column{0.42\textwidth}
      {\footnotesize

      \begin{block}{Idea principal}
      Reconstruir imágenes de pastillas y predecir su localización mediante bounding boxes.
      \end{block}

      \vspace{0.12cm}

      \begin{itemize}
        \setlength\itemsep{0.06cm}
        \item El \textbf{encoder} comprime la imagen en una representación latente.
        \item El \textbf{decoder} reconstruye la imagen de entrada.
        \item Una cabeza adicional predice la caja: \(x, y, w, h\).
        \item El modelo aprende a reconstruir la imagen y a localizar la pastilla a la vez.
      \end{itemize}

      \vspace{0.12cm}

\begin{frame}{Trabajo futuro}
  \begin{columns}[c,onlytextwidth]

    \column{0.52\textwidth}

      \begin{block}{Uso de una CNN}
      Como mejora futura, se podría sustituir o complementar el sistema actual de descriptores manuales por una red convolucional entrenada sobre las imágenes de pastillas.
      \end{block}

      \vspace{0.2cm}

      \begin{itemize}
        \setlength\itemsep{0.14cm}
        \item La CNN aprendería automáticamente patrones visuales relevantes como
         forma, color, textura, logos y marcas, sin definir cada descriptor a mano.
      \end{itemize}

    \column{0.44\textwidth}

      \begin{block}{Ventajas esperadas}
      \begin{itemize}
        \setlength\itemsep{0.14cm}
        \item Representaciones más adaptadas al dataset.
        \item Mayor robustez ante cambios de iluminación, escala o perspectiva.
        \item Es un sistema más escalable si aumenta el número de muestras.
      \end{itemize}
      \end{block}

      \vspace{0.15cm}

      {\scriptsize
      La idea sería mantener el enfoque de recuperación visual, pero usando embeddings aprendidos por la CNN en lugar de depender solo de las features implementadas.
      }

  \end{columns}
\end{frame}

% 15
\begin{frame}{Conclusiones}

  \begin{itemize}
    \setlength\itemsep{0.35cm}
    \item Se ha construido un sistema de recuperación de pastillas basado
    en descriptores clásicos (SIFT + BoW) capaz de identificar la pastilla
    correcta en el top-10 en el \textbf{89\% de los casos} bajo condiciones
    mas o menos realistas de captura gracias al DA.
    \item El sistema sería implementable como app offline (integración nativa
    con Kotlin/Swift, sin necesidad de server FastAPI). 

    \item El enfoque clásico se
    considera una ventaja en salud pública, ya que los modelos son interpretables y
    auditables, sin las limitaciones de explicabilidad del deep learning.
  \end{itemize}

\end{frame}
